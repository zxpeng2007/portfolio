# portfolio

My personal website, live at **[zxpeng2007.github.io/portfolio](https://zxpeng2007.github.io/portfolio/)**.

One static page ([index.html](index.html)) — no frameworks, no build step — served straight from this repo by GitHub Pages. Behind the page is a small 3D world drawn in pixels on a canvas: an atom, two humanoid robots in a table-tennis rally, and a meshed cantilever beam under load, all on a simulation mesh. Scrolling flies the camera through it along a path of five stops. Over it, the sections are aqua windows that can be dragged around by their title bars on desktop. There is a light and a dark theme.

The pixel type is [DotGothic16](https://github.com/fontworks-fonts/DotGothic16), self-hosted from [fonts/](fonts/) under the SIL Open Font License ([fonts/OFL.txt](fonts/OFL.txt)).

My pre-college admissions portfolio is kept at [archive.html](archive.html).
